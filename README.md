# INTERNSHIP-FINDER-APPLICATION-TRACKER
A web-based application that helps students find internship opportunities, explore company details, submit enquiries, and track their internship applications in one place.
✨ Features
Student Profile Management
Internship Search by Domain and Location
Company Details
Enquiry Module
Internship Application Tracking
Simple and User-Friendly Interface
🛠️ Technologies Used
Add the technologies you actually used in your project, such as HTML, CSS, and JavaScript.
🎯 Objective
To simplify the internship search process by providing students with a single platform to explore internship opportunities and manage their applications efficiently.
